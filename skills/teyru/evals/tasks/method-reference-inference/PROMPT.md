The Teyru class in this directory maps a list of words to their lengths.
`Lengths.of(List.of("ab", "c", ""))` must return a list of `2`, `1` and `0`.

Make the class compile and behave that way. Keep the public API
(`Lengths.of(List<String>)`). `teyru` is on PATH; use `teyru build` and
`teyru test`.
