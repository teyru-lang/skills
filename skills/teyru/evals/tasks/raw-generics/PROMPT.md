The Teyru class in this directory sums a list of integers. `Sum.of` must return
0 for an empty list and the sum of every element otherwise. The grading tests
call it with lists of `Integer` and compare the `int` result.

Make the class behave that way. Keep the public API (`Sum.of(List<Integer>)`).
`teyru` is on PATH; use `teyru build` and `teyru test` while you work.
